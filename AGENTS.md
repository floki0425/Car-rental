# AGENTS.md

## Project Overview
This is a React + Vite + Tailwind CSS + Supabase project


## Design Instructions

For all UI redesign tasks, also read and follow:

`DESIGN.md`

## Common Commands
- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build project: `npm run build`
- Run lint: `npm run lint`

## Coding Style
- Use functional React components.
- Use Tailwind CSS for styling.
- Keep components clean, reusable, and easy to understand.
- Prefer simple MVP logic before adding advanced features.
- Keep UI responsive for desktop and mobile.

## Before Making Changes
- Check the existing file structure first.
- Do not rename or move important files unless necessary.
- Explain major changes before applying them.
- Avoid adding new dependencies unless needed.

## UI Preference
- Make the design clean, premium, modern, and professional.
- Use good spacing, consistent typography, and clear sections.

Visual references are located in the `/references` folder.
Use them as inspiration only, not exact copies.
